# 세종시 BRT 환승 취약 정류장 분석

### BRT 환승 실패 위험과 교통약자 접근성을 결합한 정류장 개선 우선순위 도출

> **2026 세종특별자치시 데이터·AI 활용 경진대회 — 데이터 분석 정책 제안 부문**

세종시 버스 공공데이터와 병의원·복지시설·학교·정류장 시설 데이터를 결합하여  
**BRT 환승 실패 위험이 높고 교통약자의 대기 환경이 취약한 정류장**을 도출하고,  
정류장별 개선 우선순위를 제안한 데이터 분석 프로젝트입니다.

---

## Problem

버스 이용 불편을 단순한 평균 대기시간만으로 판단하면  
**환승 실패 가능성이나 교통약자의 실제 이용 환경**을 충분히 반영하기 어렵다고 판단했습니다.

따라서 다음 요소를 함께 고려해 정류장별 취약도를 산출했습니다.

- 버스 대기시간
- 배차간격의 불규칙성
- BRT 환승 실패 위험
- 병원·복지시설·학교 등 교통약자 관련 시설 접근성
- 정류장 쉘터 등 시설 환경

---

## Analysis Flow

```text
TAGO 버스 API 수집
        ↓
노선 · 정류장 · 도착정보 결합
        ↓
병원 · 복지시설 · 학교 데이터 결합
        ↓
Haversine 기반 반경 500m 시설 수 계산
        ↓
95퍼센타일 대기시간 및 배차 변동성 산출
        ↓
BRT 환승 실패 위험도 계산
        ↓
정류장별 취약도 점수 산출
        ↓
A ~ E 등급화 및 우선 개선 정류장 도출
```

---

## Vulnerability Score

각 지표를 `0~1` 범위로 정규화한 뒤 가중 합산했습니다.

```text
BRT 환승·대기 취약도 =

0.25 × 95퍼센타일 대기시간
+ 0.20 × 배차간격 변동계수
+ 0.25 × BRT 환승 실패 위험도
+ 0.20 × 교통약자 시설 인접도
+ 0.10 × 정류장 시설 취약도
```

교통약자 시설 인접도는 다음 비율로 구성했습니다.

```text
병원 50% + 장애인복지시설 30% + 학교 20%
```

산출된 점수에 따라 정류장을 `A ~ E` 등급으로 구분하고,  
**상위 10%인 E등급을 최우선 개선 대상**으로 정의했습니다.

---

## Policy Proposal

분석 결과를 단순 순위 제시에 그치지 않고 정책 개선 방향으로 연결했습니다.

| 등급 | 특징 | 정책 방향 |
|---|---|---|
| A | 안정적 정류장 | 모니터링 유지 |
| B | 일부 불안정 | 시간대별 관찰 |
| C | 환승 실패 위험 | 환승 시간표 보정 검토 |
| D | 교통약자 대기 취약 | 배차 및 정류장 시설 개선 |
| E | 최우선 개선 대상 | 두루타버스 연계 및 쉘터 개선 우선 적용 |

## Key Takeaway

이 프로젝트에서는 하나의 교통 지표만으로 취약 정류장을 판단하지 않고,  
**버스 운행 안정성·환승 위험·교통약자 접근성·정류장 시설을 결합해 문제를 구조화**했습니다.

분석 결과를 점수와 등급으로 끝내지 않고  
실제 개선 대상 정류장과 정책 우선순위로 연결하면서  
**데이터 분석 결과를 의사결정에 활용하는 과정**을 경험했습니다.
